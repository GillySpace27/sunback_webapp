# Fast-RHEF fork of sunkit-image, VENDORED AS A PRE-BUILT WHEEL.
#
# Keeps sunpy/sunkit-image#324 (sort-and-group rhef kernel, ~10× at our bin
# density) + #325 (analytic find_pixel_radii fast path on non-rotated HPC maps,
# ~7×); together ~2.1 s → ~150 ms for a 4096² RHEF, measured on the old Render
# box (the API now runs on Fly, DEPLOY.md). Those
# PRs are NOT in a tagged PyPI release yet, so plain PyPI would forfeit 2–10×.
#
# We no longer `pip install git+…@branch`: pip's partial ("promisor remote")
# clone of the fork flaked ~half of Render's no-cache builds
# (`fatal: early EOF / index-pack failed`). Installing a committed wheel removes
# the build-time git clone entirely → deterministic builds, same fast kernels.
#
# The wheel is the fork at commit 41e89767fc8dbd0c3799d2e3aaaf87419c67fdfd
# (fork branch solar-archive-fast-rhef: a plain merge of #324 at 6ace76e into
# #325 at e157b8d) with the non-.py files under sunkit_image/data/test/
# stripped; runtime never touches them.
# To REBUILD (deterministic; prints the sha256):
#   scripts/build_sunkit_wheel.sh <40-hex sha>
# then point the wheel line below at the new file and update WHEEL,
# WHEEL_SHA256 and SUNKIT_VERSION in scripts/smoke_rhef.py. The Docker build
# runs that smoke check right after this install.
